# Book Management System

This repository has been organized into separate frontend and backend folders.

## Structure

- `frontend/` - React + Vite client application
- `backend/` - Node.js + Express API placeholder

## Run locally

From the repository root:

- `npm run dev:frontend` to start the frontend (http://localhost:5173)
- `npm run dev:backend` to start the backend (http://localhost:5000)

Or run both in separate terminals.

## Setup

1. Install frontend deps: `cd frontend && npm install`
2. Install backend deps: `cd backend && npm install`
3. Start frontend: `npm run dev:frontend`
4. Start backend: `npm run dev:backend`

## Notes

- The frontend code has been moved into `frontend/`.
- The backend folder contains starter scaffolding. Add your API routes, controllers, and database models there.
